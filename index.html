BETA SETUP

Connect your phone to Hermes.

The current beta is intentionally terminal-driven. A guided installer is planned.

✓ Supported Hermes build✓ HMP Gateway plugin✓ Tailscale on host✓ Tailscale on phone
01

Install HMP Gateway

Install and configure the HMP plugin on the Hermes host.

HMP Gateway repository →
02

Pair your phone

Create a short-lived pairing offer.

hermes hmp pair offer --label "My iPhone"

Scan the QR, compare the security code, then confirm in the terminal.

03

Approve your bots

Request the Bot Chats you want in the app, then approve those requests in the Hermes terminal.

Developer beta HMP packaging is being prepared for public distribution. Use only pinned installation instructions published by the HMP project.
